This four-row public locale journal is retained historical unit-test input from a
failed validation attempt. Its original identifiers, timestamps and two locale
strings are preserved. It is not a complete capture or evidence of a current
package, guest, signature or capability pass.

The comparison regression reads these bytes only as fixture data. Capture adapter
tests create separate synthetic temporary files and explicitly double independent
capture validation. This directory is separate from calendar_runtime, whose
files are enumerated as SDK project inputs.
