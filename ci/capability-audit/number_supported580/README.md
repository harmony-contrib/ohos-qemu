# Supported local Number integration sources

These templates preserve reviewed source work on the single development branch.
They are source-only inputs to the existing normal source author/generator,
not standalone ready-to-run programs or runtime acceptance. The canonical
build/package/image entry points separately apply the public permission error
translation and export actual packaged seed bytes.

`templates/normal` contains the unsigned SDK producer and the existing SDK
dispatcher/plan/source manifest successors. `templates/post` preserves the native
observer build/recheck, seed and permission evidence joins, actual source/compile
export, and independent installed-image profile successors. Original resource
owners, serial cleanup, stages and security flags remain in force. `source-tools`
records the reviewed finite input preparer and explicit future identity sites.
Full provenance and finite changes remain in the retained Root evidence capsules.

The local Owner, corpus and final mandatory gate are included as unprojected
sources. Commit all business code first, then derive actual source identity DATA
from that clean HEAD with the reviewed Root author. Original normal signing,
actual SDK/native production and the independent Number QEMU closure must all
complete before acceptance. Unprojected templates do not bypass those gates.
The representative build waits for all known fixes; the other five packages wait
for complete runtime validation of the newly packaged representative.

Cloud user registration, login and account-bound cloud sync are outside the
requested scope. Local OS account isolation, permissions, ordinary networking
and offline application behavior remain mandatory. No QEMU gate has passed for
this source checkpoint.
