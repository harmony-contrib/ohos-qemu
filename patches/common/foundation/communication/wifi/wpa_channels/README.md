# Non-chip WPA 的实时信道表

与 `wpa_scan` 的真实 GET_CAPABILITY freq 路由配套使用。标准产品关闭
chip HDI 时，wifi_common 选择 WPA 软件后端；chip 产品的原路由不变。

每次读取支持频段、信道或扫描频率前重新查询真实主 STA。不能只依赖单例
构造：构造可能早于 WPA 启动；监管域变化也不是同步完成的。更新在 getter
获取同一个互斥锁之前执行，避免递归加锁。查询失败以空表替换旧表，不能
保留陈旧频段或把调用者旧输出当作新结果。空/未知扫描频段返回失败，不能
默默扩大为全频扫描。完整全频扫描仍遵循原 ScanService 明确的处理路径。

返回的 NO_IR 信道只代表可扫描的频率，不授权主动发射或 AP；WPA 和内核
继续执行监管限制。AP-only、关联、数据链路、非默认扫描调度和后台 PNO
必须另行实测；本部件不宣称这些能力已完成。
