# Public OPP transfer enums

Restore DirectionType, TransferStatus and TransferResult from the existing native
OPP constants, with the SDK's exact ERROR_ member names. Every NAPI failure is
propagated; repeated initialization owns independent objects. The fixed source
uses CRLF; the component verifies the resulting reverse patch explicitly.

This component is in the common phone/2in1 pre-traversal plan. Registration,
cached three-ABI compilation and host boundaries do not implement Bluetooth
transport or demonstrate successful file transfer. Those backend requirements
remain open until separate new-package ordinary-app tests pass.
