# Conditional self-stop for a completed SERVICE request

Source-only candidate. It has not been parsed, compiled, applied, tested or run
by this child. The parent integrates source hooks and validates a newly packaged
representative QEMU image before any remaining package matrix.

Current Settings awaits its real accessibility operations and guards destroyed
lifecycle work, but remains alive when idle. Unconditional asynchronous
terminateSelf would race a newer AMS/onRequest start. This component adds a
separate real startId-conditional IPC; ordinary terminateSelf/terminate/stop
methods and parcels remain unchanged.

The API takes the genuine delivered onRequest startId. AMS retains original
token/self/user authorization, restricts the new operation to SERVICE extension
records, and compares the exact self token's startId while holding the same
serialMutex_ used by StartAbility. It also rejects a queued start that has not
yet received a new startId. Only then does it enter the original termination
chain. A generation mismatch is ERR_OK plus stopped=false; other actual errors
remain errors. No private callback, forged record, fabricated ID, timer or
unconditional fallback supplies success.

Settings uses a finite type-only local interface for the actual native method,
because its existing prebuilt SDK26 does not contain the new source declaration.
It submits a captured genuine startId after the queue completes; false/error
keeps the queue usable for newer requests. Current action completion and
onDestroy lifecycle guards remain. The SDK source declaration is also added for
future generated SDKs; this component does not edit any installed SDK.

All 18 exact preimage/final file hashes and three actual project HEADs are in
source_states.json. The preimage is the current parent-owned build, including
existing product patches and Settings accessibility_service_completion 0001 /
0002. Unknown bytes, partial application and mixed project-file states fail.
apply.sh --source-root ROOT first checks this complete vector and the three
actual project HEADs. It copies all18 files to isolated scratch, checks that
complete preimage, patches only scratch and requires the complete final hash
vector. Before committing it rechecks every live byte/inode/mode/owner and HEAD.
Each live file is replaced atomically while retaining mode/owner; a failure
rolls owned replacements back to the original18 bytes and rechecks the complete
before vector. An unexpected concurrent edit is preserved and reported rather
than overwritten. No Git reset or whole-project replacement occurs. No guard,
scratch apply or transaction command has been executed by this child.
