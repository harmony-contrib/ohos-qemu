# Number native diagnostic source candidate

This exact component records observations only. It does not validate a callback,
public result, caller identity, image, or first artifact. Parent-owned integration
and the full EVENT-CONTRACT495.md are required before use.

Use apply.sh --source-root ROOT through the original exact helper. Component
validate() is only its own managed-file staging hook; it does not implement the
cross-project gate. The new MainThread component default verifier CLI and its
preflight_sequence(ROOT, require_patched=True) enforce the complete A+B final
vector. The legacy loader must run first for original source, and a trace-final
MainThread is skipped only after this new fixed whole-vector admission succeeds.

Fresh/final/unknown and every file's SHA are fixed in source_states.json. New
header original null means absent, not an existing empty file. Unknown/partial,
symlink, hardlink or project-revision mismatches preserve source and refuse.
No common helper or original guard is changed by this component.
