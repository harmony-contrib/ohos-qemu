# Real fixed SystemUI source provider

The original fixed SystemUI project has only Hvigor inputs. The HAP part installs prebuilt entry, statusbar and dropdown HAPs; modifying ArkTS alone does not update those binaries. This component adds one actual ohos_app that compiles all selected source modules through the original GN compile_app/Hvigor/sign-app chain. Phone builds seven modules and 2in1 builds eight. The same one compile action prevents concurrent Hvigor writes to this project. hap_list names the signed outputs at the original app install directory.

Only BUILD.gn, build-profile.json5, oh-package.json5 and hvigor/hvigor-config.json5 change. API26/Hvigor6 are used; unused Hypium is removed, and all production HAR dependencies remain local real source. Original entry module declarations, permissions, APL, ACLs, statusbar logic and the separately reviewed eight-source live-view component remain unchanged. Preparation checks the complete live-view/35-readonly source guard. The fixed OS signer already matches both original SystemUI vendor policies. Only the original release profile not-after value is renewed; every other signed field stays equal, with original OS issuer verification. No vendor row is edited.

Existing ScreenLock has no implementation in this source project. Its original independent Stage feature phone is retained byte-for-byte, fixed LFS SHA7e6d99cf44f67a421e20ef2d7a86084d52b45dc1fc4c0ea0902dd4ede47c2cc9. VersionCode1000000/versionName1.0.0, signer and profile issuer must match the new same-bundle modules. Source entry phone_entry has a distinct module name. Old ScreenLock compileAPI20 and new API26 coexistence is not assumed accepted by BMS: it is an explicit new-image installation/UI regression gate. No old package or successful prepare constitutes that gate.

The parent applies source_provider, the seven-definition HAP graph component after ContactsTheme, and prepare_dependencies.py before the actual representative build. All SDK compilation and signing happen in the original resource Owner/build; these scripts were not executed by this delivery. scripts/verify_systemui_provider_image.py checks the actual image modules against this exact build's signed output, compiled manifests/resources/ABC and OS signatures. Actual QEMU Allow/Deny/user-stop/privacy/cancel/death/recreate and original cleanup/47/48 remain mandatory and pending.
