# Real Contacts and wallpaper providers

Apply after the calendar/photos/settings/admin/MMS HAP graph components. QEMU's
Contacts alias reaches its real source ohos_app target. Both aggregate HAP groups
select one renderer: tablet for device_type=2in1, phone otherwise. Other products
retain the original Contacts prebuilt and no new wallpaper output. App source,
profile, preinstall and actual image checks remain mandatory. This GN patch alone
is not installation or runtime acceptance.
